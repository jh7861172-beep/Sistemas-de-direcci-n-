# DirecciónLab | Wiki de sistemas de dirección automotriz

Sitio estático en HTML, CSS y JavaScript. No necesita instalación ni servidor propio.

## Probar en tu computadora
1. Descomprime `direccionlab_wiki.zip`.
2. Abre la carpeta `direccionlab_wiki`.
3. Abre `index.html` en un navegador. Las imágenes SVG están en `assets/`.

## Publicar gratis con GitHub Pages
1. Crea una cuenta en https://github.com/ si todavía no tienes una.
2. Crea un repositorio nuevo. Un nombre posible: `direccionlab`.
3. Sube `index.html`, la carpeta `assets` y este `README.md` al repositorio. No subas solo el ZIP: primero descomprímelo.
4. En el repositorio, entra en **Settings → Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
7. Espera a que GitHub termine la publicación. En **Settings → Pages** aparecerá el enlace público, normalmente con formato `https://TU-USUARIO.github.io/direccionlab/`.

## Cómo actualizar la wiki
Edita `index.html` para cambiar textos, secciones, enlaces o diseño. Para cambiar diagramas, sustituye los SVG dentro de `assets/` conservando sus nombres, o actualiza las rutas en el HTML. Luego sube los cambios al mismo repositorio. GitHub Pages publicará la nueva versión automáticamente después de procesar el cambio.

## Qué incluye esta versión
- Diseño oscuro adaptable a móviles y computadoras.
- Navegación responsive.
- Buscador funcional de los cuatro sistemas.
- Fichas de dirección mecánica, hidráulica, electrohidráulica y eléctrica.
- Componentes principales, ventajas/desventajas y línea del tiempo.
- Diagramas SVG originales y fuentes de consulta.

## Nota
Es un recurso educativo introductorio. Los diagramas son esquemáticos y no sustituyen manuales de servicio específicos del fabricante.
